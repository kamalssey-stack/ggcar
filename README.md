# CarTune Pro — Kia Soul

Jetpack Compose, minSdk 26. Три экрана: ГОНКА (0–50 / 0–100 по GPS), G-СИЛА, X-RAY.
Экран подстраивается под ориентацию: на магнитоле (горизонтально) слева боковая панель.

## Получить APK через GitHub (без Android Studio)
1. Зайдите на github.com, создайте бесплатный аккаунт и нажмите New repository (название любое, например `cartunepro`).
2. На странице нового репозитория нажмите «uploading an existing file».
3. Откройте папку `CarTunePro` на компьютере, выделите ВСЁ её содержимое (включая папки `app`, `gradle`, `.github` и файлы `settings.gradle.kts`, `build.gradle.kts`) и перетащите в окно браузера.
   Важно: файлы должны лежать в корне репозитория, а не внутри лишней папки.
4. Нажмите Commit changes.
5. Откройте вкладку **Actions**. Сборка «Build APK» запустится сама (5–10 минут).
6. Когда рядом с ней появится зелёная галочка, откройте её и внизу в разделе Artifacts скачайте `CarTunePro-apk` (это zip, внутри `app-debug.apk`).
7. Распакуйте, скопируйте `app-debug.apk` на флешку и установите на магнитоле.

Если сборка красная, откройте её, скопируйте текст ошибки и пришлите разработчику.

## Что настраивать
- `RaceScreen.kt` → `FACTORY_0_100` — паспортное время разгона.
- `XrayScreen.kt` → `RATIOS`, `FINAL_DRIVE` — передаточные числа АКПП (приблизительные).
- `Telemetry.kt` → `START_KMH` — порог начала отсчёта (1.5 км/ч).
- Кнопка DEMO сверху включает симулятор для проверки без выезда.
